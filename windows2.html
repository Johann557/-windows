Windows Evolution

Die lückenlose Chronik aller Microsoft Windows Desktop-Versionen im Wandel der Zeit

17 Versionen gelistet

Windows 1.0

1985 MS-DOS Aufsatz

Der Ursprung von Microsofts grafischer Reise. Windows 1.0 war kein eigenständiges Betriebssystem, sondern eine grafische Bedienhilfe für MS-DOS.

Codename

Interface Manager

Architektur

16-Bit

Schlüsselfeatures

  • Kachel-Fenstermanagement
  • Klassisches MS Paint & Notepad
  • Reversi als erstes Spiel

Windows 2.0

1987 MS-DOS Aufsatz

Echte Flexibilität betritt die Bühne. Windows 2.0 erlaubte es Fenstern erstmals, sich gegenseitig zu überlappen und verbesserte die VGA-Grafik deutlich.

Codename

N/A

Architektur

16-Bit

Schlüsselfeatures

  • Überlappende Fenster
  • Erste Versionen von Word und Excel
  • Unterstützung für Tastatur-Kurzbefehle

Windows 3.0

1990 MS-DOS Aufsatz

Der erste große kommerzielle Erfolg. Windows 3.0 modernisierte das Speichermanagement, verbesserte die Performance und brachte das Kultspiel Solitär.

Codename

N/A

Architektur

16-Bit / Real- & Protected Mode

Schlüsselfeatures

  • Einführung des Program-Managers
  • Solitär & Minesweeper
  • Erweiterte Speichernutzung über 640 KB

Windows 3.1

1992 MS-DOS Aufsatz

Der stabile Klassiker der frühen 90er. Windows 3.1 brachte bahnbrechende Vektorschriftarten (TrueType) und ebnete den Weg für Windows in Unternehmen.

Codename

Janus

Architektur

16-Bit

Schlüsselfeatures

  • TrueType-Schriftarten integriert
  • Einführung der Windows Registry
  • Netzwerkfähige "Workgroups"-Edition

Windows NT 3.1

1993 NT Enterprise

Der Start des robusten NT-Kernels. Microsoft entwickelte NT komplett ungebunden von MS-DOS für höchste Server- und Enterprise-Stabilität.

Codename

Razzle

Architektur

32-Bit (Vollwertig)

Schlüsselfeatures

  • Unabhängiger NT-Kernel
  • Präemptives Multitasking
  • Erste NTFS-Dateisystemunterstützung

Windows 95

1995 Windows 9x

Die Erfindung des modernen Betriebssystems. Das ikonische Startmenü, die Taskleiste und echtes 32-Bit Plug-and-Play veränderten die Tech-Welt nachhaltig.

Codename

Chicago

Architektur

16/32-Bit Hybrid

Schlüsselfeatures

  • Startmenü und Taskleiste debütieren
  • Lange Dateinamen (statt 8.3 Zeichen)
  • Integrierte Internet-Explorer-Unterstützung

Windows NT 4.0

1996 NT Enterprise

Stabilität trifft Windows 95 UI. NT 4.0 brachte das neue, moderne Interface von Windows 95 in das hochstabile Firmennetzwerk.

Codename

Cairo / Shell Update

Architektur

32-Bit

Schlüsselfeatures

  • Windows 95 Shell auf NT-Basis
  • Ausgezeichnete Multi-User-Stabilität
  • Grafiktreiber im Kernel-Mode

Windows 98

1998 Windows 9x

Das Betriebssystem für das Internetzeitalter. Windows 98 verbesserte den USB-Support massiv, optimierte FAT32 und integrierte das Web tief in den Desktop.

Codename

Memphis

Architektur

16/32-Bit Hybrid

Schlüsselfeatures

  • Exzellenter USB- & AGP-Support
  • Schnellstartleiste eingeführt
  • "Active Desktop" (Web-Inhalte als Hintergrund)

Windows 2000

2000 NT Classic

Das sicherste Betriebssystem seiner Zeit. Windows 2000 kombinierte die Multimedia-Fähigkeiten der Consumer-Reihe mit der extremen Ausfallsicherheit von NT.

Codename

Windows NT 5.0

Architektur

32-Bit

Schlüsselfeatures

  • Einführung des Active Directory
  • Ruhezustand (Hibernate) nativ integriert
  • Signifikant stabilere USB-Treiberarchitektur

Windows ME (Millennium Edition)

2000 Windows 9x

Das vieldiskutierte Schlusslicht der MS-DOS-Linie. Windows ME fokussierte sich stark auf Multimedia-Inhalte, litt aber unter mangelnder Systemstabilität.

Codename

Millennium

Architektur

16/32-Bit Hybrid

Schlüsselfeatures

  • Einführung der Systemwiederherstellung
  • Windows Movie Maker debütiert
  • MS-DOS Modus wird weitgehend versteckt

Windows XP

2001 Verschmelzung

Die Legende. Windows XP vereinte endlich die Consumer- und Enterprise-Linien auf dem hochstabilen NT-Kernel und besaß ein unvergessliches blaues Oberflächendesign.

Codename

Whistler

Architektur

32-Bit / Später 64-Bit Edition

Schlüsselfeatures

  • Luna-Themendesign & Bliss-Hintergrund
  • CD-Brennen nativ im Windows Explorer
  • Sehr langlebiger Support (bis 2014)

Windows Vista

2007 NT Modern

Ein radikaler Schritt nach vorn. Trotz anfänglicher Hardware-Probleme legte Vista mit seiner gläsernen Aero-Optik und harten Sicherheitsfeatures das Fundament für die Zukunft.

Codename

Longhorn

Architektur

32-Bit / 64-Bit

Schlüsselfeatures

  • Aero Glass UI mit Transparenzeffekten
  • Benutzerkontensteuerung (UAC) für Sicherheit
  • Desktop Gadgets & Sidebar

Windows 7

2009 NT Modern

Der absolute Fan-Favorit. Windows 7 polierte die Aero-Struktur von Vista auf exzellente Performance auf und gilt bis heute als eines der besten Windows-Betriebssysteme.

Codename

Windows 7

Architektur

32-Bit / 64-Bit

Schlüsselfeatures

  • Smarte Taskleiste ("Anheften" von Apps)
  • Aero Snap (Fenster an Bildschirmränder ziehen)
  • HomeGroup für unkomplizierte Netzwerke

Windows 8

2012 Kachel-Ära

Ein mutiges, kontroverses Redesign. Windows 8 entfernte das klassische Startmenü zugunsten einer bildschirmfüllenden Kacheloberfläche für Touch-Geräte.

Codename

Windows 8

Architektur

32-Bit / 64-Bit / ARM (RT)

Schlüsselfeatures

  • Metro-Kacheloberfläche
  • Einführung des Windows Store
  • Extrem schnelle Bootzeiten durch Fast Startup

Windows 8.1

2013 Kachel-Ära

Die besonnene Korrektur. Microsoft reagierte auf weltweite Kritik und brachte mit Version 8.1 den Startknopf zurück und erlaubte das Booten direkt zum klassischen Desktop.

Codename

Blue

Architektur

32-Bit / 64-Bit / ARM

Schlüsselfeatures

  • Rückkehr des Startknopfes
  • Direktes Booten auf den Desktop
  • Erweiterte Multitasking-Optionen für Apps

Windows 10

2015 Windows as a Service

Das einigende Windows. Bringt das klassische Startmenü zurück und verschmilzt Kachel-Apps nahtlos mit Desktop-Fenstern. Entwickelt als einheitliches System für alle Gerätetypen.

Codename

Threshold / Redstone

Architektur

32-Bit / 64-Bit / ARM

Schlüsselfeatures

  • Cortana Sprachassistent debütiert
  • Neuer Microsoft Edge Browser (basierend auf Chromium)
  • Virtuelle Desktops und Task View

Windows 11

2021 Fluent Design & KI

Die moderne Gegenwart. Windows 11 besticht durch ein zentriertes Fluent-Design mit abgerundeten Fensterecken, nativer Android-App-Unterstützung und tief integrierter künstlicher Intelligenz.

Codename

Sun Valley

Architektur

Ausschließlich 64-Bit / ARM

Schlüsselfeatures

  • Zentrierte, neu strukturierte Taskleiste
  • Windows Copilot (KI-Assistent)
  • Unterstützung für Android-Apps (WSA)

Wusstest du schon?

Microsoft hielt sehr lange an der Codebasis von MS-DOS fest (bis Windows ME), während parallel die stabilere NT-Architektur für Firmen entwickelt wurde. Seit Windows XP laufen alle Consumer-Versionen ausschließlich auf dem sicheren NT-Kernel.
